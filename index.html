Questions

Common Queries

Does iPet share my voice or room data with servers?

Absolutely not. iPet is built from the ground up for zero-cloud reliance. All speech-to-text models, emotional coordinate arrays, and LLM text generation run directly on the physical 4.5 TOPS NPU chip inside the robot. It does not require an active internet connection to interact with you.

How long does the battery last on a single charge?

iPet's active battery life lasts about 4–6 hours of continuous movement, facial tracking, and vocal conversation. When battery drops below 15%, it will automatically drive back to its magnetic charging dock, connect, and charge back to full in 45 minutes.

Can I code custom apps or behaviors for my iPet?

Yes! With the Pro SDK bundle, you get full documentation and support libraries in Python and JavaScript/TypeScript. You can read capacitive sensor raw frequencies, draw custom vector frames onto the circular OLED screen, hook up sensor events to home automation systems, or feed custom prompt systems to the LLM core.
